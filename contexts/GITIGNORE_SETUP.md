# Comprehensive .gitignore Setup

**Variables**: `$VARS` are environment variables (expand them), `{vars}` are runtime values (find/calculate them), `[vars]` are template placeholders (substitute them).

**Key Paths**:
- `{project-root}` - Current project directory (find by locating .workflow/ directory)

## CHECK EXISTING GITIGNORE

**Check for existing .gitignore:**
- IF exists: Read it to see what's already ignored
- IF missing: Will create new one
- Look for marker comment `# Momentum workspace` to avoid duplicates

## DETECT TECH STACK

**Primary Source:**
- READ {project-root}/.workflow/artifacts/ITERATION.md if exists
- EXTRACT languages and frameworks mentioned

**Secondary Detection:**
- Check for language files: *.py, *.js, *.ts, *.go, *.rs, *.java, *.rb
- Check for package files: package.json, pyproject.toml, go.mod, Cargo.toml, pom.xml, Gemfile
- Check for framework markers: .next/, django, rails, vue, react
